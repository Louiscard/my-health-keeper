# 子女安装指南

> 给帮爸妈装「我的健康管家」的孩子看的。全程大约 20 分钟，其中建档采访 10～15 分钟，最好陪在爸妈身边一起完成。

## 准备

- 爸妈的手机号（用来登录爸妈自己的豆包账号）
- 一台电脑（上传 Skill 用电脑版豆包最方便）
- 爸妈正在吃的药的药盒、最近的体检单或化验单（建档时拍照用）

## 第一步：上传 Skill（电脑）

1. 下载本仓库（GitHub 页面右上角 Code → Download ZIP，解压）。
2. 打开豆包电脑版，**用爸妈的手机号登录**。
3. 左侧栏「插件 · 技能 · 伙伴」→ 顶部「技能」→ 右上角「添加」→「上传技能」。
4. 选择 `my-health-keeper` 文件夹（里面有 `SKILL.md`）。
5. 看到「技能上传成功」后，到「管理 › 技能 › 个人」里确认「我的健康管家」已经打开。

## 第二步：建一个固定入口

1. 左侧栏「项目」→ 新建项目，名字叫「**我的健康**」。
2. 在这个项目里新开一个对话，说一句：

   > 记住：问我身体的事，先查我的健康档案再回答。

3. 在爸妈的手机豆包里，把「我的健康」项目或这个对话置顶。

## 第三步：陪爸妈建档（10～15 分钟）

1. 在「我的健康」里说：「帮我建个健康档案」。
2. 让爸妈自己回答，你在旁边帮忙。管家会分 3～4 轮问，每轮最多 3 个问题：
   - 老毛病、过敏（**这个一定要问清楚**）
   - 正在吃的药 → **直接拍药盒**最准
   - 手术、住院、最近的检查 → **拍化验单**
   - 复查时间、生活习惯、紧急联系人
3. 管家读出档案摘要，爸妈确认后，它会建好「我的健康档案」，并在首页画一张健康全景图。
4. 管家问要不要开启「两周回访」和「复查提醒」，建议都开。

## 第四步：你也能看到

1. 打开管家给的档案链接 → 右上角「分享」。
2. 把你自己加为协作者（可阅读），或设成「获得链接的人可阅读」，再把链接发给自己。
3. 以后爸妈记了什么、指标怎么变，你都能看到。

## 第五步：教爸妈三句话

| 什么时候 | 怎么说 |
|---|---|
| 想吃药、拿不准的时候 | 「我能吃 XX 吗？」 |
| 量了血压血糖、医生改了药 | 「我今天血压 150」「医生给我加了个药」（直接说，或者拍照） |
| 不舒服、要去医院的时候 | 「急救卡」 |

再告诉爸妈：**按住说话就行，不用打字。**

## 常见问题

- **它没查档案，直接回答了？** 确认是在「我的健康」项目里问的；再说一次「先查我的健康档案再回答」。
- **建了两份档案？** 让管家「把两份健康档案合成一份」，或者手动把内容合到一起，删掉多余的那份。
- **想关掉回访？** 豆包左侧栏「定时任务」里找到「健康回访」，关掉或删除。
