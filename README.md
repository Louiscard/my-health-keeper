# 我的健康管家

> 给爸妈用的 AI 健康档案管家 · 一个豆包 Skill

爸妈吃哪几种药、对什么过敏、哪年做过手术、下次什么时候复查——这些事，往往只有他们自己记得个大概，孩子不在身边更是一问三不知。

**我的健康管家**是一个可以装进豆包的 Skill。装好以后，爸妈只要在豆包里说话：

- 「我能吃布洛芬吗？」→ 它先翻爸妈自己的健康档案：「您在吃防血栓的药，布洛芬先别吃。」
- 「我今天血压 150/95」→ 它帮忙记下来，和上次比一比。
- 「急救卡」→ 马上弹出一张急救信息卡：过敏、用药、病史、紧急联系人。

档案存在飞书 Wiki 里，越用越全。

## 它能做什么

| 能力 | 爸妈怎么说 | 管家做什么 |
|---|---|---|
| 采访建档 | 「帮我建个健康档案」 | 分 3～4 轮问清楚老毛病、吃的药、过敏、手术、复查；药盒、化验单拍照就行，然后建好档案 |
| 健康全景图 | （建档后自动生成） | 在档案首页画一张仪表盘：每人一张卡片，病、药、过敏、指标、下次复查，一眼看清 |
| 基于档案回答 | 「我能吃 XX 吗」「我做过什么手术」 | 先查档案再回答，说出依据；不诊断、不改药 |
| 自动记录 | 「今天血压 150」「医生给我加了个药」 | 听出新情况，主动记进档案（读数直接记，换药先确认） |
| 急救信息卡 | 「急救卡」 | 弹出一张大字卡片，可以做成手机锁屏或打印放钱包 |
| 看懂化验单 | （拍照）「帮我看看」 | 只讲异常项，一句大白话，和上次比 |
| 保健品把关 | 「这个保健品能吃吗」 | 查和在吃的药冲不冲突，提醒小心推销 |
| 看病小抄 | 「明天去医院」 | 一页给医生看的摘要：用药、过敏、最近指标、想问的问题 |
| 回访和提醒 | （定时） | 每两周问问情况；复查前三天提醒 |

## 设计原则

1. **爸妈自己用**：用的人是长辈本人，说「我」就是档案主人。称呼「您」，大白话，一次最多问 3 个问题，欢迎语音和拍照。
2. **先查档案，再开口**：档案里有的不再反问；档案里没有的不猜。
3. **不是医生**：不诊断、不让长辈自己加减停药，危险信号第一句就说打 120。
4. **记得准**：口头说的标「待核实」，拍了药盒或单子才算「已核实」。
5. **隐私**：身份证号、医保卡号不进档案；档案只分享给家里人。

## 安装

Skill 要装在**爸妈自己的豆包账号**里，一般需要孩子帮忙装一次。详细步骤见 👉 [子女安装指南](docs/子女安装指南.md)。

简单版：

1. 下载本仓库，找到 [`my-health-keeper/`](my-health-keeper/) 文件夹（里面有 `SKILL.md` 和 `页面模板.md`）
2. 用爸妈的账号登录豆包电脑版 → 插件 · 技能 · 伙伴 → 技能 → 添加 → 上传技能 → 选择这个文件夹
3. 新建一个项目叫「我的健康」，在里面说：「帮我建个健康档案」
4. 让爸妈以后有身体上的事，就到「我的健康」里问

其他支持 Skill（SKILL.md 格式）的 AI 工具也可以试；档案部分依赖飞书 Wiki。

## 已知限制

- **和孩子一起看还不太方便**：档案存在爸妈账号的飞书 Wiki 里，孩子要看，需要爸妈把文档分享出去（设成「获得链接的人可阅读」或添加孩子为协作者）。目前在豆包文档里分享和协作的操作对长辈不够友好，建议建档时由孩子顺手设置好。
- **技能不一定每次都触发**：有时豆包会用自带的医疗问答回答。建议固定在「我的健康」项目里问，并在建档后说一句「记住：问我身体的事，先查我的健康档案再回答」作为兜底。
- **建档需要 10～15 分钟**，长辈累了可以分几次完成。
- 档案里的内容由本人、家人和 AI 整理，**不能替代医生**。

## 免责声明

本项目只是一个健康信息整理工具，不提供医疗诊断或治疗建议。任何用药和治疗决定，请咨询医生或药师。出现紧急情况，请立即拨打 120。
